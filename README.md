# Estrutura de Dados para Leitura de Dados TJDFT

## 1. Sobre o Projeto

Este projeto consiste no desenvolvimento de um código em C que usa estruturas de dados para ler enormes processos do TJDFT e então entregar de maneira organizada informações relacionadas a esses processos. 
Ele entrega informações como quantidades de casos totais e específicos, além de criar um CSV com a Meta 1 dos processos. 

---

# 2. Objetivos

* Mostrar o número de processos presentes na base de dados;
* Pegar o ultimo processo;
* o id_processo do processo com dt_recebimento mais antigo;
* Processos estão relacionadas a causas de violência doméstica;
* Processos estão relacionadas a causas de feminicídio;
* Processos estão relacionadas a causas ambientais;
* Processos estão relacionadas a causas de quilombolas;
* Processos estão relacionadas a causas indígenas;
* Processos envolve causas relacionadas a infância e juventude;
* o número de dias entre dt_recebimento e dt_resolvido;
* o percentual de cumprimento da meta 1; 
* Gerar um arquivo CSV com todos os processos julgados (mérito) na Meta 1.

---
